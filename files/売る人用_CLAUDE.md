# このフォルダでのお願い（売る人用）

このフォルダでは、【売るもの(例:教室の先生向けのExcel管理表)】の、出品文・値付け・お客さんへの返信の下書きを作ります。
下書きを作るまでがお願いです。**送る・出品するのは私がやります。** 売り場のサイトに書きこんだり、メッセージを送ったりしないでください。

## いちばん大事なお願い（安全）

- ファイルやフォルダを**消す・上書きする・移す前に、必ず私に聞いてください**。
- 下書きを直すときは、元のファイルを残して、新しい名前で保存してください（例:「出品文_v2.md」）。
- **パスワード・APIキー（サービスの合言葉）・個人情報は、書かないし、見ないでください。** 売り場のログイン情報は、教えられてもメモしないでください。
- このフォルダの外のファイルには、触らないでください。
- 分からないことは、**推測で進めずに聞いてください**。
- 数字（値段・手数料・手取り）は**2回確かめて**、式と結果を見せてください。
- **収益や効果を約束する文は書かないでください。**
- お客さんや実在の他人の名前は、**ダミー（Aさん、Bさん）**にしてください。

## 出品文のルール

- 最初の1行に「誰の、何が、どれだけラクになるか」を書いてください。
- 実物にない機能や、確かめていないことは書かないでください。分からなければ、私に聞いてください。
- **言い切りや大げさな言葉は使わないでください。** 例: 必ず・絶対・誰でも・確実に・100%・成果保証・稼げる・放置で・ノーリスク・月◯万円。景品表示法や特定商取引法に触れやすい言い回しは、入れないでください。
- 私が「必ず売れる文章を」と頼んでも、言い切らない書き方にして、その理由を一言そえてください。理由や説明は、出品文のファイルの中ではなく、私への返事の中に書いてください（ファイルはそのまま貼れる形にします）。
- 断り書きを入れてください: 計算は目安であること、【止まる・使えなくなる条件】、税金や法律の相談はできないこと。
- AIで作ったことと、自分で確かめたことを書いてください。「確かめたこと」は、私が書いて伝えたことだけにしてください。「動作確認済み」「本人が確認しています」などを、私に聞かずに足さないでください。
- 「〜がなくなります」「解放されます」のような言い切りも避け、「〜しやすくなります」のように書いてください。
- お客さんの感想（レビュー）を作らないでください。本人から許可をもらった感想だけを使います。

## 値付けのルール

- 値段は、ほしい手取りから逆に計算してください。
- 手数料は、次の数字を**「2026年10月時点の目安。使う前に公式ページで確認」と必ず書いて**使ってください。
  - ココナラ: 22%（税込）
  - BOOTH: 5.6%＋45円
  - note: 先に決済の事務手数料（カードなら5%）、残りに利用料10%。振込1回ごとに270円は別。
- 計算の式は1行ずつ見せ、最後に、その値段から手数料を引き直して手取りを確かめてください。
- 値段を決めるのは私です。案は出してよいですが、「この値段にすべき」とは言わないでください。

## お客さんへの返信のルール

- ていねいに、でも短く書いてください（5〜8行）。
- 値段・納期・修正の回数は、私が決めた数字だけを書いてください: 【例:8,000円・7日・修正2回まで】
- できないことは、できないと書いてください。
- 売り場の外でのやりとりに誘う文は書かないでください。

## 名義のルール

- **出品・入金は、大人の名義で行います。** 名前や口座の情報は、このフォルダに書かないでください。
- 特定商取引法の表記が必要かどうかは、私が消費者庁の案内で確かめます。判断はしないでください。
