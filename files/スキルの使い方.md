# 特典③ スキル3点の使い方

スキルとは、Claude Codeに「この作業は、この手順でやってね」と覚えさせておく仕組みです。
1つのスキルは、1つのフォルダと、その中の `SKILL.md` というファイルでできています。

この特典には、次の3つが入っています。

| スキル名 | 何をするか | こんなときに |
|---|---|---|
| `kensan-check` | 検算（数字を、もう一度べつの方法で計算して確かめる） | AIが作った表の数字が合っているか知りたいとき |
| `listing-check` | 出品文チェック | 出品文の下書きを、出す前に見てほしいとき |
| `tedori-calc` | 手取り計算 | 売り場と金額から、手元に残るお金を知りたいとき |

---

## 1. 置き場所

### おすすめ：練習用フォルダの中に置く

練習用フォルダ（本で作ったフォルダ）の中に、次の形で置きます。

```
練習用フォルダ/
└── .claude/
    └── skills/
        ├── kensan-check/
        │   └── SKILL.md
        ├── listing-check/
        │   └── SKILL.md
        └── tedori-calc/
            └── SKILL.md
```

- `.claude` は、名前の最初に「.」（ドット）がつくフォルダです。パソコンの設定によっては、ふだんは見えません。
- そのフォルダでClaude Codeを開いたときだけ、スキルが使えます。

### パソコン全体で使いたいとき

どのフォルダでも使いたいときは、自分のホームフォルダの中の `~/.claude/skills/` に、同じ形で置きます（例: `~/.claude/skills/kensan-check/SKILL.md`）。
`~` は「自分のホームフォルダ」という意味です。

はじめは、練習用フォルダの中に置くのがおすすめです。

### 置き方のコツ

- フォルダの名前（`kensan-check` など）は変えないでください。この名前が、呼ぶときの名前になります。
- Claude Codeに「特典のスキル3つを、このフォルダの `.claude/skills/` に置いて」と頼んでもかまいません。置いてよいか確認が出たら、**場所を読んでから**許可してください。
- 置いたのに出てこないときは、Claude Codeを一度終わらせて、開き直してください。

---

## 2. 呼び方

呼び方は2つあります。

### ① 名前で呼ぶ

チャット欄に `/` と名前を打ちます。後ろに、たのみたいことを続けて書けます。

```
/kensan-check 記録シート.xlsx
/listing-check 出品文.txt
/tedori-calc ココナラで3,000円
```

`/` を打つと出てくる一覧にスキルの名前があれば、置き場所は合っています。

### ② ふつうの文でたのむ

名前を打たなくても、ふつうにたのめば、Claude Codeが内容を見て、合うスキルを自分で選ぶことがあります。

```
この表の数字が合っているか検算して
この出品文、出す前に見てくれる？
BOOTHで1,500円売れたら、手取りはいくら？
```

ただし、**いつも選ばれるとはかぎりません。** このスキルを使ってほしいとはっきり決まっているときは、①の名前で呼ぶ方法がおすすめです。

---

## 3. 使うときの注意

- **練習用フォルダで、ダミー（練習用の作りもの）のデータで試してから**、本番に使ってください。
- パスワード・APIキー・本物の個人情報（実在の人の名前や住所）は、貼らないでください。
- `kensan-check` は、元のファイルを書きかえない手順にしてあります。それでも、ファイルを直す・保存する確認が出たら、読んでから許可してください。
- `listing-check` は一般的な注意です。法律の判断ではありません。売り場のルールは、売り場の公式ページで確認してください。
- `tedori-calc` の手数料は2026年10月時点の目安です。料金は変わるので、最新の金額は各売り場の公式ページで確認してください。税金の相談ではありません。
- スキルに書いたことは「お願い」です。Claude Codeが必ずそのとおりに動くとはかぎりません。出てきた答えは、自分の目で確かめてください。
