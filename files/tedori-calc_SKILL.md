# 手取り計算スキル

手取り（てどり）とは、「売れた金額から、売り場に払う手数料を引いて、手元に残るお金」です。
このスキルは、売り場と金額から手取りを計算し、**式を見せて**説明します。

## 手数料の目安（2026年10月時点）

| 売り場 | 手数料の計算 |
|---|---|
| ココナラ | 売れた金額の22%（税込） |
| BOOTH | 売れた金額の5.6% ＋ 45円（2025年10月28日に改定。前は5.6%＋22円）。円未満は切り上げ（公式のお知らせより） |
| note | ① 先に決済の事務手数料を引く（カード5%、携帯電話のキャリア決済15%など）→ ② 残りの金額に利用料10%（定期購読マガジンは20%）。①②とも小数点以下は切り捨て。<br>別に、振込手数料270円が**振込1回ごと**にかかる |
| 直接取引（知り合いなど） | 0% |

**料金は変わります。最新の金額は、必ず各売り場の公式ページで確かめてください。** 答えのたびに、この一言をそえます。
ココナラとBOOTHの出金（売上を引き出すとき）の手数料は、ここにはふくめていません。

## 手順

1. **売り場・金額・件数を確かめる。** 足りなければ聞きます。noteなら払い方（カードかどうか）も聞きます。わからなければ「カード払いの例」として計算します。
2. **手数料を計算する。** 上の表の式で、1件あたりの手数料を出します。式を書きます。
3. **手取りを出す。** 売れた金額 − 手数料。
4. **もう一度、別のやり方で確かめる。** 例: 「手取り＋手数料＝売れた金額」になるか。2回の答えが合ってから答えます。
5. **件数があれば、かけ算する。** noteは、振込手数料270円を「振込1回分」として最後に1回だけ引きます（1件ごとには引きません）。
6. **月額の元を取る件数（聞かれたとき）。** Claude Codeの月額は、**読む人に聞きます**（円でいくらとして考えるか）。ドルを円に直す計算はしません（為替は変わるので、数字を決めません）。
   月額の金額を自分で決めません（「仮に◯円」の表を作らない）。答えを待つあいだに例を見せるなら、本の例「月約3,000円とした場合」の1つだけにし、「例です」と書きます。
   件数 ＝ 月額 ÷ 1件の手取り を、小数点以下を切り上げた数。かけ算で、届くかどうかも見せます。
   書き方は「◯件で月額に届く計算です」とします（「元が取れます」と言い切らない）。
7. **年20万円の話（聞かれたとき）。** 次のことだけを伝えます。
   - 給料を1か所でもらい、税金が天引きされている人は、給料以外の「所得」が年20万円を超えると、所得税の確定申告が必要になる目安です。
   - 所得は売上ではなく「収入 − 必要経費」です。
   - これは所得税の話で、**住民税は別**です。住民税の申告が必要な場合があるので、お住まいの市区町村のページで確認してください。
   - 「これは一般的な情報で、税金の相談ではありません。くわしくは税務署・市区町村・税理士に確認してください。」
8. **答えの形。** 次の順で書きます。
   - 結論（手取り◯円）
   - 計算式（1行ずつ）
   - 注意（料金は2026年10月時点の目安。最新は公式ページで確認）

## 計算の例（1,000円が1件売れたとき）

- ココナラ: 1,000 × 22% = 220円 → 手取り **780円**
- BOOTH: 1,000 × 5.6% = 56円、56 + 45 = 101円 → 手取り **899円**
- note（カード払い）: 事務手数料 1,000 × 5% = 50円 → 残り950円 × 10% = 95円 → 手数料 50 + 95 = 145円 → 手取り **855円**。1件だけ売ってすぐ振り込むと、さらに270円を引いて585円。

## 注意

- 売れる件数の予想や、もうかるという約束はしません。
- 税金・法律について、その人の場合どうなるかの判断はしません。
