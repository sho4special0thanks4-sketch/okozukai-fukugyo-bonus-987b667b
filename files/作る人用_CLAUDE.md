# このフォルダでのお願い（作る人用）

このフォルダは、【フォルダの呼び名(例:練習用の作業場)】です。
ここでは、【作るもの(例:教室の先生向けのExcel管理表)】を作ります。
読む人は、パソコンに慣れていない人です。説明は、むずかしい言葉を使わずに書いてください。

## いちばん大事なお願い（安全）

- ファイルやフォルダを**消す・上書きする・移す前に、必ず私に聞いてください**。何を、どこで、なぜ変えるかを先に見せてください。
- 直すときは、元のファイルを消さずに、新しい名前で保存してください（例:「管理表_v2.xlsx」）。
- **パスワード・APIキー（サービスの合言葉）・個人情報は、書かないし、見ないでください。** そういうファイルがあっても開かずに、私に知らせてください。私が貼ってしまったときは、メモやファイルに残さず、その場で注意してください。
- このフォルダの外のファイルには、触らないでください。
- 分からないことは、**推測で進めずに聞いてください**。
- 数字（合計・手取りなど）は**2回確かめて**、確かめた式と結果を私に見せてください。
- 「必ず売れる」「稼げる」など、**収益や効果を約束する文は書かないでください**。
- 実在する他人の名前や会社名は使わず、**ダミー（架空の名前）**にしてください。

## 作るもののルール

### ファイル名

- ファイル名は「日付_中身_版」の形にしてください。例:「2026-10-21_月謝管理表_v1.xlsx」
- 日本語のファイル名でかまいません。空白は使わず、「_」でつないでください。
- 同じ名前のファイルがあるときは、上書きせずに版の数字を1つ上げてください。

### 保存先

- できあがったものは「【できあがり】」フォルダに保存してください。
- 作る途中のメモや、作るためのプログラムは「【作業用】」フォルダに入れてください。
- フォルダがなければ、作る前に聞いてください。

### ダミーデータ

- 名前・住所・電話番号・メールアドレス・金額は、**ぜんぶ架空**にしてください。
- 架空の名前は、ありふれた下の名前だけ（例:みお、そうた）か、「Aさん」の形にしてください。
- ファイルの中の目立つところに「サンプルの数字は架空です」と書いてください。

### できあがりの確認の手順

作り終わったら、「できました」と言う前に、次の順で確かめて、結果を表で見せてください。

1. ファイルが開けるか、壊れていないか。
2. 計算があるものは、サンプルの1行を、ファイルの式を使わずに計算し直して、表の値と比べる。
3. ボタンや▼の選択があるものは、どう確かめたか（確かめられなかったなら、そう）を書く。
4. 結合セルを使っていないか（Excelのとき）。
5. 本物の名前や連絡先が入っていないか。
6. 私が自分の目で見るべきところを3つ挙げる。

確かめられなかったことは、「確かめられなかった」とそのまま書いてください。
